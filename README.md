# NetWatch

NetWatch is a Python-based network and system monitoring platform built with Flask and psutil.

## Features

- CPU monitoring
- Memory monitoring
- Disk monitoring
- Network traffic monitoring
- Upload/download speed
- Local IP detection
- System information
- System uptime
- Running process monitoring
- Active network connections
- REST API endpoints
- Health monitoring endpoint
- Real-time dashboard
- Modular Python architecture

## Technology Stack

- Python
- Flask
- psutil
- REST API
- JavaScript
- HTML
- CSS
- Gunicorn
- Pytest
